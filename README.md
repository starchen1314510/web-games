# 网页游戏厅（Web Games）

一个纯前端的经典小游戏合集：打开首页可以看到所有游戏，点击卡片即可进入对应游戏页面。

无需安装依赖、无需构建、无需后端，双击 `index.html` 就能玩。

## 运行方式

方式一：直接双击 `index.html` 用浏览器打开（全部为本地资源，`file://` 协议即可运行）。

方式二：启动一个静态服务器（推荐，避免个别浏览器对本地文件的限制）：

```bash
cd web-games
python3 -m http.server 8080
```

然后访问 http://localhost:8080 。

## 技术栈

- 原生 HTML5 + CSS3 + JavaScript（ES6），零第三方依赖
- Canvas 2D 绘制游戏画面与逐帧动画，部分棋盘类游戏使用 DOM + CSS 过渡
- `requestAnimationFrame` + 基于时间的步进，帧率无关
- `localStorage` 保存各游戏最高分 / 最佳用时 / 最佳步数 / 最少步数
- 五子棋内置启发式评分 AI（活三、冲四、成五分别加权），连连看使用两折内路径判定
- 三消宝石按「匹配检测 → 重力坍缩 → 连锁结算」流水线消除，迷宫用递归回溯生成完美迷宫并以 BFS 求解提示路径
- 泡泡龙用六边形网格 + 同色 BFS 判连、顶部连通性 BFS 判悬空；极速赛车按 `y = horizon + k·t²` 透视映射车道与车速；黑白棋用位置权重表 + α-β 剪枝极小极大搜索
- 数独用回溯填满整盘后逐格挖洞，每挖一格跑一次限量求解器保证唯一解；21 点用 6 副牌牌堆与软/硬点换算（A 先记 11，爆点时降 10）；迷你高尔夫按 6 段子步进做圆-矩形分离轴反弹，沙地与水塘改变摩擦系数；青蛙过河按行类型分流，河道判定载具携带、车道判定 AABB 重叠
- 吃豆人用固定种子 LCG 在奇数格上 DFS 挖走廊，再随机打通隔断形成环路；幽灵按「禁止反向 + 曼哈顿贪心」选向，能量豆期间改为反向逃离。炸弹人爆炸沿四个方向逐格推进，遇硬墙中断、遇砖块销毁即停，命中其他炸弹触发链式引爆
- 数织的完成判定基于「行列连续段与提示完全匹配」而非比对唯一解，因此多种形态都能通过；生成时补齐全空行与全空列并约束黑格比例在 34%–68%。飞镖按极坐标把落点映射到 20 个扇区 × 单/双/三倍环，501 收镖强制双倍或红心，爆分与剩 1 分都回到本轮起始分
- 点灯的初始灯阵用「倒序点击」生成（从全灭状态随机点若干次），因为翻转操作自逆，所以必然有解；格子底色预渲染成离屏精灵，避免逐帧重建渐变。海战棋的 AI 用「命中后把四邻未打格推入候选队列、击沉后清空」的追击策略，且只依据自己的命中记录判定沉船
- 小行星用角度制飞船 + 速度阻尼 + 最大速度限制，命中判定走平方距离避免开方；叠塔用「区间求交」计算保留宽度，错开部分转为带旋转与重力的碎片粒子
- 水管工的管网由「随机 DFS 生成覆盖全部格子的连通树 + 每格随机旋转」构造，判定时从左上角 BFS 注水，注满全部格子就等价于所有接口都成对匹配；汉诺塔用抛物线插值做搬运补间，飞行期间跳过目标柱顶盘的常规绘制
- 弹球台每个物理步不超过 1/180 秒，球与线段按「最近点 + 法向分离」求解，挡板按角速度换算踢球冲量；钓鱼用「钩子跟随 + 上钩后连点填充进度条」的两段式交互，鱼按水深区间加权刷出
- 台球用固定 1/240 秒子步进求解等质量圆碰撞，袋口的「免碰库半径」与「落袋判定半径」取同一个值，避免球停在袋口既不掉也不弹；保龄球在屏幕空间用固定半径全解球瓶碰撞，绘制时按伪透视的 y 微缩放，十局计分走「全中看后两投、补中看后一投」的加成累加
- 一笔画按奇点度数限制起点（无奇点时任意点可起）、用邻接表 + 边去重逐条落笔；塔防把敌人位置换算成「沿折线走过的弧长」，塔在射程内选最靠近终点的目标索敌，炮弹命中后按半径做范围伤害
- 二十四点用分数约分做精确四则运算，再递归枚举「任取两数做一次运算」的全部组合来出题，保证每题可解；飞刀把角度差归一到 ±π 后与已插刀比对判撞，并将每盘刀数封顶为 10 以避免禁区总和超过一周而必然无解；节奏以固定种子 LCG 生成拍点谱面，命中音效由 `AudioContext` 实时合成；接龙按「背面 9px / 正面 25px」堆叠，列高超出牌桌时整列等比压缩，撤销以整盘 JSON 快照回滚
- 华容道用矩形重叠检测（`canPlace`）+ 逐格推进（`shiftAxis`）实现拖动滑行，撤销栈记录每次单格移动；密码破译按「先扣精确位置、再用剩余槽位算颜色命中」两步产出金实点与空心圈，避免同一颗彩珠被重复计数
- 打字狂潮以「前缀锁定」选词：已锁定的单词优先匹配，否则在所有可匹配单词中取最靠警戒线（`y` 最大）的一个，连击倍率封顶 3 倍；射箭把靶面视为过靶心的垂直平面，箭矢跨越该平面时用线性插值求着弹点，再做同心圆环判分，避免高速箭矢穿过环缝
- 跳棋只允许黑格上的斜向移动与跳吃，评估函数按「兵 / 王身价 + 过河推进 + 中心控制 + 边线惩罚」累加，着法先按吃子路径长度排序再进 alpha-beta 剪枝搜索，低难度时随机放水；单词寻宝按 8 个方向逐格铺词并做冲突检测（同字母可交叉复用），拖动时把落点投影到行列对角线上并校验共线，正反向都能命中
- 星尘闪避用「指针目标点 + 速度插值」跟随，弹幕分瞄准扇射、环爆、雨线、螺旋四类，受伤后进入短暂无敌并清空近身子弹；判定半径小于视觉半径以提升容错。像素跳跃按 x / y 分轴解算 AABB 碰撞，带土狼时间与踩怪反冲，关卡数据驱动（地面留坑、浮岛成阶梯），横向相机只跟随不纵向滚动
- 拼图把程序化风景（渐变夜空 + 星点 + 三层正弦山脊 + 水面倒影 + 暗角）预渲染到离屏画布，再按格切块，只做「两块交换」并用归位个数判定完成；猜词用两遍扫描做字母判定（先扣完全正确位，再用剩余字母池给黄标），157 个答案词与 700 多个合法词分表存放
- 光影摩托按固定步长逐格推进，电脑对三个可选方向按「射线长度 + 开放邻格数 + 离墙距离」打分；空气曲棍球用 1/120 秒预测冰球落点（含两侧反弹）驱动电脑走位，球拍自身速度参与碰撞后的球速计算
- 斗兽棋把「鼠入水、狮虎跳河、陷阱降战力、鼠可吃象」写成统一的 `canCapture`，再叠 α-β 剪枝极小极大（按吃子价值排序着法）出棋；数桥先用随机 Prim 生成树，再剪叶降到目标岛数、把每条边拆成 1-2 座桥，胜利需「数字全满足 + BFS 连通」双条件
- 记忆序列用 `AudioContext` 实时合成四个音高，亮灯 / 熄灯时长随序列长度递减，答对得分与序列长度成正比；街头投篮按「拉拽距离 × 系数」换算出手速度，入筐判定比对前后两帧的篮圈平面跨越，再按是否碰框区分三分与两分
- 登月舱用「重力 + 推力 + 角速度」积分，着陆需同时满足平台命中、法向速度、横向速度与机身角度四项阈值；全垒打按球与球棒的横向距离分级判定（全垒打 / 安打 / 界外 / 挥空），投球时长逐球缩短并叠随机扰动，连击加成封顶 +3
- CSS Grid / Flex 布局，响应式适配桌面与移动端

## 新增一款游戏

大厅的卡片由数据驱动，添加新游戏只需两步：

1. 在 `games/` 下新建游戏目录，放入 `index.html` 与脚本；
2. 在 `assets/js/hall.js` 的 `GAMES` 数组中追加一项：

```js
{
    id: 'my-game',
    title: '我的游戏',
    tag: '休闲',            // 卡片上的小标签
    category: '休闲',       // 分类筛选依据
    desc: '一句话介绍玩法。',
    controls: '方向键 / 空格',
    url: 'games/my-game/index.html',
    thumbBg: 'radial-gradient(120% 120% at 20% 0%, #1b2e4d 0%, #0d1524 70%)',
    glow: 'rgba(79, 140, 255, .38)',
    icon: `<svg viewBox="0 0 64 64">...</svg>`
}
```

刷新大厅即可看到新卡片，顶部统计数量也会自动更新。
